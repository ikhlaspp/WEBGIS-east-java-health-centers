Queue framework tables app.jobs/failed_jobs use framework column types (payload, queue, attempts, reserved/available/created timestamps; failed UUID/connection/exception/failed_at). Restrict job payloads to IDs/parameters, never credentials. No reset-password email feature is assumed; provisioning and operator token issuance are controlled operator procedures.

Geocode_reviews.source_id memiliki FK ke data_sources.id dan harus sama dengan facility_snapshots.coordinate_source_id ketika review dipilih. Geography indexes cast geom where needed; PostGIS types live in pinned extensions schema. No numeric ratio is independent of run. Source/boundary/alias rows referenced by validated or ever-published releases become immutable; corrections create new source/set/alias and release version. Composite constraints and cross-row validations are detailed in WF-034; aggregate values are derived, not user editable.
