# Selected historical boundary reference

24 October 2026. Technical source-selection decision under the accepted acquisition scope, not a new user acceptance or an invented independent review.

Use the BPS-sourced Indonesia COD-AB v01 district layer distributed by OCHA ROAP/OCHA FIS and HDX. The official catalogue explicitly assigns CC BY-IGO, identifies BPS as source, and records the April 2020 geometry edition. Its 2025 review and 2026 resource-file modification dates are not substituted for the geometry date. Each selected feature states valid_on=2020-04-01. The source CRS is OGC:CRS84 (WGS84 longitude/latitude).

This selects an available licensed historical reference instead of the unapproved June 2026 BIG candidate. The accepted WF-G2 supplement moves exact source selection into acquisition/curation and authorizes free official sources; the WF-019 mixed-period exploration policy permits explicit year labels. This decision does not enable a strictly aligned 2023 geometry claim. All analysis and map metadata must preserve the actual 2020 boundary date alongside the 2023 master and 2024-S1 facility snapshot. A future strict historical mode requires additional evidence and must remain disabled until that evidence exists.

The national member contains 7069 district objects. East Java contains all 666 master district codes across 38 parents, plus one separately coded Perairan water object (ID3522888). The district selection preserves 603 Polygon and 63 MultiPolygon objects exactly; the water object is retained separately and receives no district population/area join. P-codes map through their explicit ID prefix and exact BPS text code, without name-based guesses. Names and original properties remain unchanged for later harmonization review.

Retain the supplied title, BPS/OCHA/HDX attribution, licence link, changes statement and non-endorsement notice in derived datasets and public map credits. The catalogue is https://data.humdata.org/dataset/cod-ab-idn and its metadata API is https://data.humdata.org/api/3/action/package_show?id=cod-ab-idn . Attribution and changes are machine-readable in selected-boundary-source.json.

Acquisition verifies the ZIP byte ranges, total size, stable ETag and member CRC; SHA-256 covers the complete uncompressed district member. The full national ZIP was not downloaded, so no full-ZIP SHA-256 is claimed. Raw sources and extracted geometry remain private/ignored. The earlier BIG candidate is retained only for comparison and is not the selected release source.

WF-059 acquisition criteria are met. Topology, spatial joins, coordinate review and publication acceptance remain later tasks; ready_for_public_release stays false. Acquisition completion does not certify the research dataset or claim that 2020 and 2023 geometries are identical.
